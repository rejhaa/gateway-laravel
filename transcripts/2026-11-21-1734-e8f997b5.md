#### Where the build differs from the design

`DESIGN.md` is updated in place for all of these.

- **Rules in one place.** `app/Processes/InboundPurchasing/InboundPurchasing.php` holds the read, write and never-write lists, the policy sentences, the 14-day cap and the rule list. A new rule is one class under `Rules/` plus one line there. A new process is a directory plus one line in `config/gateway.php`.
- **Simpler "Why" fold.** It shows the quote, where it was found, and the gateway's reasons. It does not mark every condition pass or fail, because rules return only their failures.

- **Unknown write outcome.** If Odoo times out on a write and the follow-up read also fails, the proposal stays `applying` until someone presses "Check Odoo again", instead of being marked failed.
