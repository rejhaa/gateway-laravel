# Claude Code session transcripts

The prompts typed in this project and the answers Claude gave, one file per session, oldest first. The tool calls between a prompt and its answer are counted and their content is left out. `bin/transcripts` writes these files from the session logs Claude Code keeps on this machine, so run it again after a session to add it or to bring a continued one up to date.
